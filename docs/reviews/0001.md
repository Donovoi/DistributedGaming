# Detractor record: first Rust harness

## Round 1: design

An independent detractor agent reviewed the design before implementation.

| Finding | Action |
| --- | --- |
| A single-thread baseline can overstate benefit. | Added a local baseline with the same tile and thread count. |
| Small chunks can defeat a timeout. | Added an absolute deadline and a slow-drip test. |
| Missing or overlapping tiles can look valid. | Check identities, bounds, sizes, repeated IDs, overlaps, and gaps. |
| A model profile can imply unsupported safety. | Kept the profile as a contract. No model output is executed. |
| A percentage can overstate game progress. | Fixed milestone weights. Game milestones stay pending. |

## Round 2: implementation

The independent detractor reviewed Rust, CLI tests, the progress checker, and CI. The detractor ran the initial 15 Rust tests and 4 Python tests. All passed.

| Finding | Action |
| --- | --- |
| The score checker allowed reweighting. | Compare goal, IDs, weights, and acceptance text with the PR base. Add regression tests. |
| Corrupt pixels lacked an end-to-end test. | Return a valid header with one changed pixel. Require CLI failure and no report file. |

No confirmed false-success defect was found in assembly or wire checks. This does not prove that no defects remain.

## Final follow-up

A fresh independent detractor ran all 16 Rust tests and 6 Python tests. All passed. The reviewer checked the claims and scanned source and docs for private data. A report path in the README could have left a raw report in the repo root. The procedure now writes into ignored `runs/`; root `run-*.json` files are also ignored.

The reviewer required the final release hash to match a physical-PC run. The final binary was copied and hash-checked on all five PCs. Both cases were repeated and passed all 24 pixel checks. The validation record and redacted reports now describe that final binary. CI remains the last M1 gate.

## Remaining limits

- Fixed CPU scene only. No GPU or game interception.
- One job at a time per worker. Equal row partitions. No load balancer.
- CPU work is bounded but not preempted by the socket deadline.
- Raw reports contain addresses and must remain private.
- The local baseline is not the final fastest-PC game baseline.
- Physical-PC smoke tests show correctness and a slowdown, not a game benefit.
