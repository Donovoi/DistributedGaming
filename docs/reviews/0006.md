# Selected game baseline review

Date: 2026-11-24.

Scope: pin a limited Counter-Strike 2 spectator baseline. Complete M3 only. M4 through M8 remain pending.

## Round 1: design challenge

The design reviewer required a fixed game, demo, camera, playback interval, actual window size, saved settings, and effective frame cap. The collector checks those conditions before and after each run. It compares the executable to the expected hash and checks the active demo header. It rejects a run with RenderDoc loaded.

The reviewer required useful timing coverage, bounded clock uncertainty, and a completed log. The accepted series set limits before measurement: 19.3 to 19.6 seconds of selected data and at most 50 ms logger-clock uncertainty. The collector waits for the logger's stop response, checks one second of file stability, and checks the copy hash. It records its own source hash.

The reviewer required honest boundaries. The record states the unproved 250 ms pause-notification assumption, the difference between window size and internal render scale, and the limits of camera endpoint checks. It reports present-call intervals separately from unmeasured input and display delay. The earlier capture is linked by game build and scene identity; it does not certify the timed runs' pixels or close M4.

## Round 2: code and evidence challenge

The independent reviewer found no blocking defect or privacy leak and accepted the limited M3 result. On the remote PC, the reviewer matched all four original CSV hashes and every exported row, the private summaries, both sets of effective setting and demo readbacks, the tick-stop messages, and the clock-window arithmetic. The baseline and progress checkers passed. All 14 staged file blob identities matched the remotely validated snapshot.

Remote checks tested staged tree `798703dd5c29e61d7ec69c264d7126e46945284f` on repository base `9a2c8d9fa9356ee080bef6901e938a0580d2ecbc`. The progress policy's six regression tests and Python compilation checks also passed there. Separate negative checks rejected a changed p95, a nonfinite interval, a repeated timestamp, and a false selection flag, including cases with recomputed file hashes.

The reviewer kept M4 through M8 pending. Notification delay, internal render scale, continuous camera state, input and display delay, fastest-PC comparison, replay correctness, and speedup remain unproved. Required CI checks must pass for the final PR head before merge.
