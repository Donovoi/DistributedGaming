# Vulkan observer review

Date: 2026-11-24. Scope: shader identity, command lifetimes, and forwarding checks. Progress stays at 50%. M5 remains pending.

## Round 1: design challenge

The design reviewer required a process-scoped observation layer before any replacement. Mandatory forwarding must remain separate from optional records. Logging failures, limits, unsupported paths, and missing lifetime tails must make evidence incomplete. No observation lock may cross a downstream call. Keep no caller-owned pointer after a call.

The design also required module/pipeline lifetime separation, handle reuse checks, command reset and secondary-command handling, and tests with the unchanged native oracle. Descriptor templates and resource ownership belong to the next slice. Dispatch recording and submission are not completion or CPU-consumption proof.

## Round 2: code and evidence challenge

The independent reviewer found five defects. Cleanup after destruction could erase a new object with a reused handle. Repeated live shader/pipeline handles needed reference counts. Truncated submissions could report a complete command list. Unknown dispatches did not taint their command buffer. Shader-object binds could leave a stale target identity.

The implementation now retires records before destruction, counts duplicate live references, marks conflicting identities unknown, records command-list completeness, and invalidates stale bindings. Regression tests exercise reentrant reuse, duplicate handles, partial submissions, mixed known/unknown dispatch, and core/KHR extension forwarding. The reviewer also required query counts to remain separate from executed calls and full-coverage claims to remain absent.

The first real loader attempt exposed an ELF symbol collision. Private negotiated function pointers fixed it. A C check now guards pointer ownership. Remote tests passed on the two fixed native inputs, including unavailable logs, existing logs, and forced write failure. No local tests were run.

The final reviewer accepted the fixes and evidence with no remaining blocker for this scope. Read-only inspection of the saved final run confirmed identical oracle JSON across all five modes for each input, clean normal logs, and matching source/library hashes. The final code passed 15 remote Rust tests and both C checks. Generation checks also keep a new instance or device dispatch entry from being erased by old cleanup.
