# Validation record

Date: 24 November 2026. Scope: Rust transport and correctness harness.

## Physical-PC test

Five user-selected Linux PCs were reached through SSH. One PC coordinated the run and rendered one tile. Four others ran one worker each. The coordinator had 32 logical CPUs and an RTX 4000 Ada. Three workers had RTX 3070 cards. The last had two GTX 1080 Ti cards. GPUs were not used.

The same Linux release executable ran on all five PCs. SHA-256:

```text
c32025712173ebd95992a30b16f27406483939b8028389fb4c3d573ff4a95a41
```

Active physical wired interfaces reported 1000 Mb/s. Direct Tailscale probes from the coordinator used local-network endpoints and reported 0 to 1 ms. This is a path check, not a sustained bandwidth benchmark. No relay was reported in those probes.

Workers bound only to their Tailscale address. Each accepted 24 connections and then exited. No service was installed. All four worker processes exited with code 0.

## Procedure and results

Each case used four `--worker IP:47000` options and `--frames 10 --warmup 2 --timeout-ms 10000`. The coordinator rendered one tile. Each frame had five row partitions. The local baseline used five threads and the same partitions. Mode order alternated. Exact comparisons ran after timing. All frames used a full-frame local reference.

| Case | Size | Samples per pixel | Local median | Local p95 | Distributed median | Distributed p95 | Exact checks |
| --- | --- | ---: | ---: | ---: | ---: | ---: | --- |
| Small | 320 x 180 | 4 | 4.681 ms | 4.884 ms | 11.387 ms | 15.110 ms | 12/12 passed |
| Large | 640 x 360 | 16 | 38.403 ms | 42.109 ms | 73.358 ms | 75.459 ms | 12/12 passed |

Returned pixel payload per frame: 184,320 bytes for the small case; 737,280 for the large case. Headers and network overhead are additional. Distributed/local time ratios were about 2.43 and 1.91. Higher means slower.

These are the final-binary runs. An earlier build also passed both cases. After the last source change, the final binary was copied to all five PCs. Its hash was checked on each PC. Both cases were then repeated. Only the final reports are published here.

The [small report](run-small.redacted.json) and [large report](run-large.redacted.json) retain raw timing samples. Addresses were replaced with labels. The automatic `physical_host_count_verified` field remains false: software cannot establish physical placement. Separate SSH inventory and matching binary checks provide this record's host evidence.

## Limits

These are short smoke tests under uncontrolled host load. No confidence interval is claimed. They measure a synthetic CPU workload, not GPU speed, game FPS, or input-to-display delay. Do not use these results to claim that a game is faster or slower when distributed.

Game adapters, captured resources, shader partitioning, history handling, and a controlled game benchmark remain pending. A library entry does not close the game-baseline milestone.
